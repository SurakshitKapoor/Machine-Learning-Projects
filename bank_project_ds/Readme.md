

# Bank Customer Churn Prediction

## Project Overview
This project predicts whether a bank customer is likely to leave the bank using machine learning classification models.

## Objectives
- Analyze customer data and identify churn patterns.
- Preprocess data and engineer relevant features.
- Train and evaluate classification models.
- Tune the best-performing model to improve prediction performance.

## Machine Learning Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Data Preprocessing
4. Feature Engineering
5. Model Training and Evaluation
6. Hyperparameter Tuning using GridSearchCV
7. Model Saving and Prediction

## Models
- Decision Tree Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score

## Current Results
The initial Decision Tree model achieved:
- Accuracy: 78.4%
- Precision: 45.6%
- Recall: 51.4%
- F1-score: 48.3%
